One menu instead of several apps. 一個選單，取代好幾個 App

Hidden files used to mean a defaults command, Night Shift a trip through Displays. Now it is a row in the menu bar, its state written beside it: awake until 18:30, 101 items in the Trash. 顯示隱藏檔案本來要打一行 defaults，夜覽要進「顯示器」才找得到。現在是選單列裡的一列，右邊直接寫著狀態：保持清醒到 18:30、垃圾桶有 101 個項目。

Also in the menu: screenshots you annotate where you took them, and text and QR recognition that never leaves this Mac. See the editor 選單裡還有拍完就地標註的截圖工具，以及完全留在這台 Mac 上的文字與 QR 辨識。看看截圖工具

Why it lives in the menu bar 為什麼放在選單列

A shortcut, a menu row and a submenu are the whole interface. Nothing opens behind your work, and nothing asks twice. 快速鍵、選單裡的一列、一層子選單，就是全部的介面。不會有視窗開在工作後面，也不會問第二次。

  • Instead of a Terminal command取代一行終端機指令

    Showing hidden files or hiding the desktop icons normally means writing a defaults key and restarting Finder. Here it is one row, and the row says what just happened. 顯示隱藏檔案、隱藏桌面圖示，平常得先寫 defaults 再重啟 Finder。這裡就是選單裡的一列，而且會直接告訴你剛才做了什麼。

  • Instead of three menu-bar utilities取代三個選單列小工具

    Keep Awake, screen cleaning, audio recording and the screenshot tool share one menu item, so there are fewer apps to install and fewer icons up top. 保持清醒、螢幕清潔、錄音和截圖共用同一個選單項目，少裝幾個 App，選單列也少幾個圖示。

  • Permissions once, in one window權限只問一次

    Accessibility, Screen Recording, Automation and the microphone are listed in a single setup window. A switch that is missing one explains what is off instead of throwing a dialog at you mid-task. 輔助使用、螢幕錄製、自動化與麥克風集中在同一個設定視窗。缺權限的開關只會說明少了什麼，不會在做事做到一半時跳出詢問。

  • Your order, not mine選單照你的習慣排

    Hide the switches you never use and drag the rest into place. The order and the shortcuts live in config.json, under your Application Support folder. 用不到的開關藏起來，其他的拖曳排序。順序和快速鍵都存在 Application Support 底下的 config.json。

What is in the menu 選單裡有什麼

The menu holds the switches and the two capture tools. A row that needs a permission says so instead of prompting; toggles show a check, actions say what they did. 選單裡是全部的開關，加上兩個擷取工具。需要權限的那一列會直接說明，不會自己跳出詢問；切換類顯示勾選，動作類回報剛才的結果。

Screenshots and text recognition need Screen Recording, which macOS applies after a relaunch. Everything else runs straight from the menu. 截圖與文字辨識需要螢幕錄製權限，macOS 會在重新啟動後生效。其餘的項目直接在選單裡就能用。

Screenshots, annotated where they were taken 拍完，就在原地標註

The screen freezes the moment the shortcut is pressed, the selection stays where it is, everything outside it dims, and the toolbar sits under the region. There is no second window to switch to. 按下快速鍵的瞬間畫面就凍結，選取範圍留在原地，範圍外變暗，工具列就放在範圍下方。不用切到第二個視窗。

  • Ten tools: rectangle, ellipse, line, an arrow in three styles, freehand, highlighter, text with a bubble, numbered markers, mosaic and blur. 十種工具：矩形、橢圓、直線、箭頭（直線、曲線、折線三種）、手繪、螢光筆、附對話框的文字、編號標記、馬賽克與模糊。
  • Click a mark to move or resize it, ⌫ to delete it, ⌘Z and ⇧⌘Z to undo and redo. 點一下既有的標註就能移動、縮放，⌫ 刪除，⌘Z、⇧⌘Z 復原與重做。
  • Enter copies, Space saves to ~/Downloads, P pins the image on screen, Esc closes. ⇧-click composes several windows into one capture. Enter 複製、Space 存到 ~/Downloads、P 釘在螢幕上、Esc 關閉。⇧ 點擊可以把幾個視窗拼成一張。
  • The colour under the pointer is shown while you select; C copies it as HEX, RGB or HSL. 選取時就看得到指標下的顏色；按 C 複製成 HEX、RGB 或 HSL。
  • Pinned images resize with the scroll wheel and fade with ⌘-scroll. 釘在螢幕上的圖片用滾輪縮放、⌘ 加滾輪調整透明度。
  • Recognition uses the same overlay and runs on device: select a region and read its text or QR code, or copy it straight away. 文字辨識用同一個覆蓋層，完全在本機執行：選一塊區域，讀出裡面的文字或 QR 碼，也可以直接複製。

Install安裝

Releases are built by CI and signed with a self-signed certificate rather than a paid Developer ID, and they are not notarized. macOS blocks the first launch — once, not every time. release 由 CI 建置，用固定的自簽憑證簽章，而不是付費的 Apple Developer ID，也沒有 notarize。所以 macOS 會擋下第一次啟動——只有一次，不是每次。

  1. Download the zip from Releases and move Panelumi.app to /Applications. 從 Releases 下載 zip，把 Panelumi.app 放進 /Applications。
  2. Double-click it, click Done on the warning, then allow it under System Settings › Privacy & Security › Open Anyway. 點兩下開啟，警告視窗按 Done，再到系統設定 › 隱私權與安全性 › 仍要打開。
  3. Grant Accessibility, Screen Recording, Automation and Microphone once in the setup window. Later updates keep them. 在設定視窗裡一次授予輔助使用、螢幕錄製、自動化與麥克風權限。之後更新都會保留。
  4. Check for Updates… in the menu compares the running version with the latest GitHub release. It never checks on its own. 選單裡的 檢查更新… 會拿目前版本和 GitHub 上最新的 release 比較。Panelumi 不會自己檢查。

Or build it from source或從原始碼建置

git clone https://github.com/jwcrystal/panelumi.git
cd panelumi
swift test
./scripts/build-app.sh
open build/Panelumi.app

Needs macOS 14+ and the Xcode command line tools. ./scripts/setup-signing.sh makes a local certificate so every rebuild keeps its permission grants. 需要 macOS 14 以上與 Xcode 命令列工具。./scripts/setup-signing.sh 會建立本機憑證，讓每次重建都保留權限。
