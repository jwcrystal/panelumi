# Panelumi 0.13.0

The highlighter draws like a marker, the pointer shows what it can drag, and
apps built on Panelumi can add their own rows to the menu.

## Screenshot

- The highlighter is a marker band instead of a translucent pen: it blends with
  what it crosses (multiply on light backgrounds, screen on dark), ends flat,
  and sizes itself from its own width. Its row in the toolbar shows that width
  in points and has two drawing modes.
- The pointer shows what a drag will do: resize arrows over the region and
  annotation handles, an open hand over an annotation, and the tool's cursor
  inside the region once editing starts.
- Undo and redo only touch the marks in the current capture. The toolbar style
  is a preference for the next mark and no longer changes when a mark is
  undone.

## For apps built on Panelumi

- `LaunchOptions.menuItemProviders` appends rows to the status-bar menu after
  the built-in switches, without changing the catalog.
- A provider can ask for the menu to be rebuilt (`bind(rebuildMenu:)`), so it
  can add or remove rows and change titles at any time, and submenu entries
  can be greyed out.

## Fixed

- A screenshot is never saved at a pixel density higher than the display's.
  Two saves on a 2x display had come out at about 300 dpi instead of 144 dpi;
  an oversized capture is now scaled down evenly to the display's density, and
  `PANELUMI_CAPTURE_DIAGNOSTICS=1` prints the sizes and scales involved (#56).

## Download

`Panelumi-0.13.0.zip` is signed with the same certificate as 0.12.2 but not
notarized, so macOS blocks the first launch:

1. Replace `Panelumi.app` in `/Applications` with the new copy, double-click it
   once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then
   authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/Panelumi.app` does the same from a
terminal. Updating from 0.12.2 keeps the Accessibility, Automation and Screen
Recording grants.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
