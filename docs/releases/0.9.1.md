# SwitchDeck 0.9.1

No new switches and no behaviour changes: this release moves the download here
and changes how the build is signed.

## Changed

- **The download lives here now.** Releases are published from this repository,
  and **Check for Updates…** reads them from here.
- **Hardened runtime.** Every build is signed with the hardened runtime and a
  two-key entitlements file (Apple Events for appearance and Finder, audio input
  for Recording), so a downloaded build is as hardened as a notarized one would
  be.
- **One version number.** The tag, the bundle's version keys and these notes are
  checked against `VERSION` before a release is built, so a release can no
  longer ship a build that reports a version other than its tag.

## Unchanged

- The 20 switches, the screenshot editor, text and QR recognition, recording,
  the shortcuts and the settings panes are the same as 0.9.0.
- The switch and annotation-tool lists are pinned by tests, so a later change
  fails the build instead of quietly dropping one.

## Download

`SwitchDeck-0.9.1.zip` is signed with a stable self-signed certificate but not notarized, so macOS blocks the first launch:

1. Move `SwitchDeck.app` to `/Applications`, double-click it once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/SwitchDeck.app` does the same from a terminal. This is the first release signed with that certificate, so coming from 0.9.0 asks for Accessibility, Automation and Screen Recording once more; later releases keep them. Recognize Text needs Screen Recording.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
