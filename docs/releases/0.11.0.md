# Panelumi 0.11.0

SwitchDeck is now Panelumi. This release renames the app, its bundle identity
and its code modules.

## Breaking

- **New bundle identifier.** `io.github.jwcrystal.switchdeck` became
  `io.github.jwcrystal.panelumi`. macOS treats it as a different app, so Screen
  Recording, Accessibility, Automation and microphone permissions are granted
  again on first use.
- **New data location.** Settings and shortcuts live in
  `~/Library/Application Support/Panelumi`, and recordings in `~/Music/Panelumi`.
  The previous `SwitchDeck` folders are left untouched and are not imported, so
  shortcuts and settings start from their defaults once.
- **No in-place upgrade.** Download the zip below and move `Panelumi.app` to
  `/Applications`. Then delete the old `SwitchDeck.app`: it still finds this
  release through the old repository path and will keep offering an update it
  cannot install.
- Screenshots are named `Panelumi_Screenshot_<date>_<time>` from now on.

## Renamed

- App, executable and About window: Panelumi.
- Bundle: `Panelumi.app`; the code modules are `PanelumiKit` and `PanelumiCore`,
  previously `SwitchKit` and `SwitchDeckCore`.
- Repository: `github.com/jwcrystal/panelumi`. Links to the old address redirect.

## Unchanged

- Every switch, the screenshot editor, text and QR recognition, and audio
  recording behave as in 0.10.0.
- The license stays Apache-2.0, and the trademark notice follows the new name.
- The signing certificate is the same one 0.10.0 used.

## Download

`Panelumi-0.11.0.zip` is signed with the same self-signed certificate as 0.10.0
but not notarized, so macOS blocks the first launch:

1. Move `Panelumi.app` to `/Applications`, double-click it once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then
   authenticate.
3. Launch it again, and remove the old `SwitchDeck.app` from `/Applications`.

`xattr -dr com.apple.quarantine /Applications/Panelumi.app` does the same from a
terminal. Recognize Text and the screenshot tool need Screen Recording.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
