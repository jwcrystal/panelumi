# Panelumi 0.12.2

A new app icon: the letter P, its counter lit.

## Icon

- The icon is a white P on a graphite tile, with a warm light in its counter —
  the second half of the name, *lumi*, without needing a second hue. The old
  mark was a single outlined toggle: it said "a switch" but nothing about which
  one, and its hollow track disappeared below 32 px.
- Same grid as before — an 824 squircle on a 1024 canvas — so it keeps its
  weight next to its neighbours in the Dock, and its transparent corners.
- Nothing in the app itself changes; this release is the icon.

## Download

`Panelumi-0.12.2.zip` is signed with the same certificate as 0.12.1 but not
notarized, so macOS blocks the first launch:

1. Replace `Panelumi.app` in `/Applications` with the new copy, double-click it
   once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then
   authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/Panelumi.app` does the same from a
terminal. Updating from 0.12.1 keeps the Accessibility, Automation and Screen
Recording grants.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
