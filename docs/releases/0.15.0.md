# Panelumi 0.15.0

Nothing looks different in this release. It opens the two places an extension
needs so extra features can be built on the same Core: a page in Settings and a
row in the status-bar menu.

## Extension points

- Settings takes extra pages. A provider returns a page's id, title, symbol and
  a view; pages follow the built-in ones, in provider order. With no providers
  the window is exactly as before. Pages are read again every time Settings
  opens, so one that appears later shows up without a relaunch.
- A status-bar row added by a provider can hold a shortcut recorded in
  Settings › Shortcuts, and that shortcut runs the same action as a click. The
  shortcut fires as soon as the row is in the menu, rather than after the next
  config change.
- Settings › Shortcuts still lists every built-in switch, hidden ones included,
  and dims a row that is hidden or currently unavailable.
- A repeated provider identifier is skipped instead of adding the same page or
  row twice.

## Notes

- Both seams are API-level. An app with no providers behaves as it did in
  0.14.0, and its settings file is unchanged.
