# Panelumi 0.11.1

Signing only: this build carries the new release certificate. Nothing in the app
changed since 0.11.0.

## Permission grants reset

The release certificate was replaced, so macOS sees a different signer. After
updating, grant Screen Recording, Accessibility, Automation and microphone
access again the first time each feature asks. The bundle identifier did not
change, so settings, shortcuts and the update check carry over.

## Unchanged from 0.11.0

- App, executable and bundle: Panelumi, `Panelumi.app`,
  `io.github.jwcrystal.panelumi`.
- Modules `PanelumiKit` and `PanelumiCore`; repository
  `github.com/jwcrystal/panelumi`.
- Every switch, the screenshot editor, text and QR recognition, and audio
  recording.
- License Apache-2.0.

## Download

`Panelumi-0.11.1.zip` is signed with the new self-signed certificate but not
notarized, so macOS blocks the first launch:

1. Replace `Panelumi.app` in `/Applications` with the new copy, double-click it
   once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then
   authenticate.
3. Launch it again and re-grant permissions as they are requested.

`xattr -dr com.apple.quarantine /Applications/Panelumi.app` does the same from a
terminal.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
