# Panelumi 0.12.1

The capture overlay opens already looking the way it will stay, and About says
what the menu replaces instead of describing the app it started as.

## Screenshot

- The overlay appears in its finished state. It used to fade in with the live
  desktop showing through, undim the window under the pointer one frame later,
  and wait for a later capture before it could show the hints and the colour
  readout. The view is now drawn once before the window is put on screen, the
  pointer's window is picked up front, and the first frame is identical to one
  taken a second later.

## About

- The tagline under the title is now **One menu instead of several apps.**
  (「一個選單，取代好幾個 App。」) The old line, "Menu-bar switches for macOS",
  was written when the menu held switches alone. It now also holds the
  screenshot editor with in-place annotation and audio recording, so the text
  described a smaller app than the one in the window.

## Download

`Panelumi-0.12.1.zip` is signed with the same certificate as 0.12.0 but not
notarized, so macOS blocks the first launch:

1. Replace `Panelumi.app` in `/Applications` with the new copy, double-click it
   once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then
   authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/Panelumi.app` does the same from a
terminal. Updating from 0.12.0 keeps the Accessibility, Automation and Screen
Recording grants.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
