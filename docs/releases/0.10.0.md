# SwitchDeck 0.10.0

The screenshot editor's toolbar is redesigned, and the project is now licensed
under Apache-2.0.

## License

- **Apache-2.0.** The source is now released under the Apache License 2.0, with
  a `NOTICE` and `TRADEMARKS.md`. Versions published earlier under the MIT
  License remain available under their original terms.

## New

- **Toolbar hints and shortcuts.** Hovering a tool shows its name and shortcut;
  the tools have single-letter shortcuts (`R O L A D H T N M B`), `⇥` hides the
  toolbar, and shortcuts are ignored while dragging.
- **No Select button.** With no tool picked you select, move and resize marks
  directly; click the active tool again, or press `Esc` or `V`, to put it down,
  and `⌫` deletes the selected mark.
- **Shared colour palette.** Ten colours, recently used, a custom page (hex and
  RGB) and an eyedropper (`I`). Colour and line width are remembered between
  launches.
- **Watermark sub-bar.** On/off, position (or tiled), size and colour sit in the
  options row; **More…** has the rest. Settings › Screenshot sets the default
  position, size, angle, opacity and colour.
- **Extension hooks.** A host package can add a capture toolbar item, take over
  a capture, and supply its own app identity (`SwitchDeckCore`).

## Changed

- Toolbar popovers open away from the selection, and the toolbar sits at the
  bottom edge when the selection is close to the screen edge.
- Screenshots are sized in points and tagged with their resolution.
- The colour under the pointer before a selection is read in sRGB.

## Fixed

- Text lays out while typing the way it is drawn.
- Recognize Text window: `⌘C`, `⌘A` and the other editing shortcuts work.
- A flaky trash-count test no longer fails intermittently.

## Download

`SwitchDeck-0.10.0.zip` is signed with the same self-signed certificate as 0.9.1 (permissions are kept) but not notarized, so macOS blocks the first launch:

1. Move `SwitchDeck.app` to `/Applications`, double-click it once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/SwitchDeck.app` does the same from a terminal. Recognize Text needs Screen Recording.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
