# Panelumi 0.12.0

The screen freezes the moment the capture shortcut is pressed, pinned images
can be moved and zoomed, and the menu shows which version is running.

## Menu

- A version row sits under **Check for Updates…**, so the running build is
  visible without opening Settings › About.

## Screenshot

- The screen freezes when the capture shortcut is pressed: the overlay samples
  the frame you saw instead of whatever is animating behind it.
- Pinned images open over the region they were captured from at 100%, take a
  drag to move, and zoom around the pointer with the wheel or a trackpad pinch
  (10–400%). A pill appears on hover with 25/50/100/200/400%, copy and close;
  ⌘-scroll still changes opacity.
- Screen Recording is checked before the overlay opens; a missing grant opens
  the permissions checklist instead of an overlay that cannot work. The
  checklist now counts Screen Recording and says when a grant needs a relaunch.
- The keyboard stays on the live overlay, including when another Panelumi
  window takes focus.

## Fixed

- A duplicate Traditional Chinese string entry (no visible effect).

## Download

`Panelumi-0.12.0.zip` is signed with the same certificate as 0.11.1 but not
notarized, so macOS blocks the first launch:

1. Replace `Panelumi.app` in `/Applications` with the new copy, double-click it
   once, click **Done**.
2. System Settings › Privacy & Security › Security › **Open Anyway**, then
   authenticate.
3. Launch it again.

`xattr -dr com.apple.quarantine /Applications/Panelumi.app` does the same from a
terminal. Updating from 0.11.1 keeps the Accessibility, Automation and Screen
Recording grants; coming from 0.11.0 or earlier asks for them once more.

## Requirements

- macOS 14 or later
- Xcode command line tools (Swift 5.9+)
